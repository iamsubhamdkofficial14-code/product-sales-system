About the Project

This project is a Product Sales Management System developed using HTML, CSS, JavaScript and Python Flask.

It displays product information such as product ID, product name, quantity sold, price per unit and total sales. Python automatically calculates the total sales based on quantity and price.

The system also allows users to add new products through an interactive form. This project demonstrates the basic use of frontend and backend technologies in web development.
